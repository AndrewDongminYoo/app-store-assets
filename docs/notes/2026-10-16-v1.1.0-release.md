## Default consumer installation

Prism Defense's ignored `tools/app-store-assets` checkout was clean, had no ignored files, and used the verified personal upstream before the update.
It moved from v1.0.0 at `d162b8297eb7e4be510c281868abb1bcffcaae47` to detached v1.1.0 at `994c6b4507210e4188c897dc79af8639e26b59c1`.
The prior tag remains available, and the updated checkout is clean.
The existing adapter already selected this directory when `APP_STORE_ASSETS_ROOT` was absent, so no installer, dependency or new runtime-selection abstraction was added.

Before the update, `env -u APP_STORE_ASSETS_ROOT merry screenshots prepare-android` exited 2 because the installed v1.0.0 CLI did not recognize `--platform android`.
After the update, both commands completed successfully with `APP_STORE_ASSETS_ROOT` removed from the child environment:

```sh

env -u APP_STORE_ASSETS_ROOT merry screenshots prepare
```

Each command returned 12 images, and the manifests, source hashes and final image hashes were verified.
Android returned bundle `2d72bb434445aefb20520133f9b3c5941ecd9abd323a39a085842fc30a304a19`; iOS returned `a6f5b52477b8a6180e8977bb67e192f08caf8b2077dcafeda16a32c7e0d78952`.
